Verteilerly — Documentation

Documentation for telecommunications distribution frames in LSA+ technology: cover sheet, frame layout and strip sheets from one data model instead of copied spreadsheets. This page describes every function of the program in the order in which you meet it at work.

1   Overview

A distribution frame consists of bays, a bay of strips, a strip of pins, a pin of the two wires a and b. Two wires together are one pair (DA). Across them lie the cables: a cable takes up a contiguous block of pairs, if need be across several strips. A jumper connects two wires inside the frame and is kept at both ends.

Everything is in one project file. Three kinds of sheet come out of it:

SheetWhat is on it
Cover sheetTitle, frame, structure, key figures and the project data as a list. It carries no title block — it is one itself.
Frame layoutEvery strip as a row of pairs, the cables as blocks in it. Two bays share one sheet and lie crosswise; a single bay stands upright. Each bay gets a sheet of its own as soon as the frame has more than two bays or one bay carries more than thirteen strips.
Strip sheetOne per strip: pin, wire, color, designation, jumper, remark and the cable column.

Preview, PDF and Excel workbook draw the same sheet model — what is in the preview is in the print as well.

2   Creating and saving a frame

File ▸ New frame… (Ctrl+N). The dialog has two halves: on the left the frame, on the right the project data.

  • Frame name and frame number — they stand in the title block of every sheet and can be changed later under Edit ▸ Project data.
  • Sheet template — which sheet layout is to apply; changeable later.
  • From template — the supplied structures and the ones you stored yourself are in the drop-down menu.
  • Custom — bays, strips per bay and pairs per strip. There, 8, 10 and 20 pairs are offered; any other number is typed in under Custom. Underneath, the result is shown as you go: 4 strips, 40 pairs. A checkbox stores the measurements as a template right away.
  • Advanced frames: set up each bay separately — the checkbox puts a table with one row per bay in place of the two numbers: how many strips it carries and how large they are. This is how an unevenly equipped frame is built — one bay with two 20-pair strips next to two bays with ten 10-pair strips. One strip size per bay. Such a frame can be stored as a template as well — the file then carries one row per bay.
  • Project data — company, customer, author and so on. Whatever is kept in the defaults is already filled in.

A structure built like this can be stored as a template: in the dialog itself or later through Edit ▸ Save as template…. It becomes a YAML file in the working folder and appears in the menu at once.

Saving is done with Ctrl+S as .vtly.json — readable JSON with a format version; older versions are still read. When you close with unsaved changes the program asks; the buttons are Save, Discard and Cancel.

3   The editor

On the left the frame overview: every strip a box of pair cells, bays side by side, the cables as blocks. A click selects a pair, a double click terminates a cable or opens an existing one.

On the right the strip view of the chosen strip with the columns pin, color, designation, jumper (two fields), remark and cable. Color, designation, jumper, remark and the cable label can be changed; pin, wire and cable position are fixed.

Text options — next to the strip selector are five buttons: align left, center, align right, as well as F for bold and K for italic. They act on the selected cell and show what applies there. Pressing an alignment again takes it back — then what the sheet template holds for that column applies again.

Several cells at once: select several cells — drag across the column with the mouse button held down, or click single ones with Ctrl — and every press of a button applies to all of them. Splitting and the percentage too. All of them get the same thing, not each its own opposite; which way it goes is decided by the cell the cursor is on. Whatever in the selection cannot be styled stays untouched.

Styleable are color, designation, jumper and remark; for pin, wire and cable the buttons are off. The two jumper fields belong to one cell of the sheet and therefore carry the same style. The style belongs to the frame, is kept in the project file and applies on the sheet, in the PDF and in the Excel workbook as well.

Splitting a cell — the button with the divided box turns a cell into two labeling fields side by side; the percentage field next to it says how wide the right one is (10 to 90 %). Editing then happens in two input fields — Tab jumps from the left one into the right one, Esc discards. Switching between the halves does not leave the cell, and a click somewhere else takes nothing with it: what was typed stays. On the sheet there is no line between the two: there it looks like one cell holding two entries. In the strip view a fine dotted line hints that there are two fields.

Splittable are designation and remark; for color and jumper the button is off. If the split is undone, the text of the right field is kept and merely appears nowhere any more. In Excel and CSV both entries stand one after the other in one cell — a grid has no half column.

Searching. Edit ▸ Search… (Ctrl+F) searches the whole frame: color, designation, jumper field — targets in the chosen notation and notes —, remark, the labels of the cables as well as the project data including own fields and the frame name. The second text of a split cell counts as well. The search runs as you type, from the second character on; upper and lower case make no difference.

The list names for every match where it lies (bay, strip, pin), which field it is and what stands in it. A double click, Enter or Go there switches to the strip and puts the cursor on the cell; the status bar at the bottom repeats what was found. Matches in the project data open the Project data dialog instead — that is where they are. The word searched for last is back in the field the next time.

Del clears the selected cells without opening them first — several at once as well. What is deleted is the content, not the form: a split cell loses both texts and stays split, a cable cell loses its label, not the cable. For pin and wire the key does nothing, and while editing it deletes characters as usual.

Enter closes the entry and goes one row down — as in a spreadsheet: a column is filled from top to bottom without having to press the down arrow every time as well. The next keystroke opens the field there by itself. If the entry was not accepted — an unreadable jumper, say — the cursor stays put: there is something to put right.

Out of a split cell it goes straight down as well — out of the right field too. If the cell below is split as well, the cursor lands in its right field again: a column of extensions can be typed from top to bottom without clicking in between. If it is not split, only the cursor moves on.

The strip is chosen from the drop-down menu or stepped through with the two arrows next to it (Alt+← and Alt+→); at the first and the last entry the respective arrow is off.

Under the menu bar lies the toolbar with what is needed most often: new frame, open, save, PDF, terminate, edit and remove a cable, and the preview.

View ▸ Show preview (F9) shows and hides the sheet preview, View ▸ Dark appearance (Ctrl+D) switches the color set. The sheet stays untouched by it: paper is white.

The preview shows the finished sheet as it would come out of the printer — the same drawing the PDF is made from. At the top the sheet is chosen: drop-down menu, two arrows and a counter (3 of 6). Underneath stands which sheet template applies; it is changed under Settings ▸ Sheet template. Every entry shows up immediately — what is here is in the print as well.

4   Cables

Terminating — Edit ▸ Terminate cable… (Ctrl+K) or a double click on a free pair. Label, cable type and size are to be given; strip and from pin come from the selection. Of that, terminate follows the cable size — the normal case is that a cable is terminated completely; whoever wants to shorten it sets the number down afterwards, and a note says how many pairs stay unterminated.

Editing — a double click on a terminated cable or Edit ▸ Edit cable… (Ctrl+Shift+E). Label, cable type, size and length can be changed, and the dialog carries the button for removing it as well.

Larger and smaller — Of that, terminate can be set here just as when terminating: the cable grows and shrinks at the end, the start stays where it is. What becomes free is free again, including the wire colors the program put there. If the strip is not enough, the same overflow dialog asks as when terminating; if another cable is in the way, this is reported and nothing is changed. Strip and from pin are fixed — for a different position take the cable off and terminate it anew.

The label can also be overwritten directly in the cable column of the strip view — where it stands. That holds for a cable created without a label as well.

Removing — Edit ▸ Remove cable (Ctrl+Shift+K), after selecting a pair with a cable.

Overflow — if a cable does not fit onto the strip completely, a dialog asks what is to happen with the rest: continue on another strip (with strip and starting point) or let it lapse. A continued cable stays one cable with several sections.

Shortened — if a cable is terminated with fewer pairs than it has, (shortened) stands behind its name; the frame layout adds shortened: 4 of 6 pairs. That way the sheet shows that wires are left over.

Wire colors — the cable type fills the color column by itself: J-Y(St)Y and the VDE color code for telecommunications cables layer by layer, star quads in pairs, DIN 47100 as a list. The cable types are YAML files in the working folder and can be extended.

The color sequence belongs to the cable: if cable type or size changes, the colors follow, and if the cable is taken off, they go with it — the next line has a sequence of its own. The yardstick is what the program set: as long as exactly that still stands in a cell, it changes it again. What you entered by hand stays; only the checkbox Also replace wire colors changed by hand in the edit dialog overwrites that as well.

5   Jumpers

Every wire has two jumper fields side by side — one per jumper, with a heading above them. The target is entered as an address of strip, pin and wire:

NotationExample
without a prefix1 1a
with a hyphen1-1a
with L before the stripL1 1a
with L and a hyphenL1-1a

Which of them is shown is set under Settings ▸ Notation of the jumpers. Everything is always read: any form may be typed, no matter which one is set, and in the project file the address stands unchanged as 1 1a. Whoever switches has to touch neither their projects nor their habits.

The counterpart enters itself: a jumper is one object that is kept at both ends. Whoever types both targets into one field (3 2a  5 4a) gets them distributed over both fields. On the sheet they stand side by side in one cell — there it should not show that these are two fields.

Checked while being entered: a jumper onto itself, a target that does not exist in the frame, the same counterpart twice or a third jumper on the same wire are refused — the message stands in the status bar, and what was there stays untouched. So what does not go through is not half taken over either.

A note instead of a target — Settings ▸ Allow free text in the jumper field also permits „external", „to the terminal block" or „n/a". To begin with this is off: whoever enters targets only wants a typing mistake reported as a mistake, not left standing as a note. A note takes up one of the two fields, stays in it and is not mirrored — it belongs to the wire. What can be read as a target stays a target even then.

6   Project data

Edit ▸ Project data… (Ctrl+B). What is here appears in the title block of every sheet.

Frame name and number stand at the top. They cannot be deselected — a sheet without a frame name would be none.

Every field has a check mark. A deselected field disappears from the sheet together with its label — a row „customer" without a customer would be worse than none at all — and keeps its content: whoever wants to leave out the installation number for this print only does not have to delete it. All and None set every check mark at once.

These fields exist:

FieldOn the sheet
Company, customermulti-line address
Installation number, customer numberInstallation, Cust. no.
Created on, created by,
revised on, revised by,
checked on, checked by,
drawn on, drawn by		 one row of date and name per pair
Initialsthe initials of the author
Document titlethe heading of the cover sheet

Company and customer carry an address, not a line: both fields are multi-line, name, street and town stand one below the other on the sheet, the label only at the first line.

Own fields are freely named pairs such as Location: basement. Add field appends a row, Remove field takes the selected one out; field name and content are typed in the list itself. The check mark row Show on says on which kinds of sheet they appear — cover sheet, frame layout, strip sheets. A deselected kind of sheet leaves the content untouched, it merely does not show it. On the frame layout they stand where the strip would be: this sheet shows every strip, so not a single one.

Changing the wording — the switch Advanced: change the wording on the sheet in the selection row folds out a list next to the fields: on the left the default word, on the right your own. Where customer stands, client may stand. Only the word is changed — content, check marks and order stay — and it applies on all sheets and in the Excel workbook. Reset to default writes the default word back everywhere. Only what differs is kept.

Defaults for new frames — Settings ▸ Defaults for new frames… carries the same fields and writes them into the Verteilerly.conf; a button takes them over from the open frame. When a frame is created they are already filled in; checked is only what they fill. Edited project data do not change the defaults by themselves — otherwise the last customer would overwrite them unasked. An open frame stays untouched: there, what is in the file applies.

On small screens — no dialog grows larger than the screen it opens on; if it stands partly beside it, it moves fully onto it. If the fields do not fit one below the other, a scroll bar appears: the content scrolls, Apply and Cancel stay firmly underneath. If there is room enough, nothing of the scroll bar is to be seen.

7   Sheet templates

How the sheet looks is said by a sheet template; what is on it comes from the project. Four are supplied:

TemplateWhat for
StandardAll columns, narrow cable column with a turned name.
Knapp (sparse)A pure jumper sheet without designation and remark, cable column wide and horizontal.
Ausführlich (detailed)Large type, high rows, one bay per sheet.
Mit Anschriften (with addresses)The title block of the sample sheets: top left the matrix of date and name with created, revised and checked, bottom left frame, number and strip, on the right two boxes with the addresses of company and customer.

It is chosen when a frame is created and later under Settings ▸ Sheet template… (Ctrl+Shift+B). The choice belongs to the workplace, not to the single frame: it is kept in the Verteilerly.conf and applies to preview, PDF and Excel workbook.

A sheet template of your own is a YAML file in the subfolder blattvorlagen/ of the working folder. It states only what it wants differently:

id: eng
name: "Eng"
rand: 8
zeilenhoehe_max: 7
spalten: [stift, ader, farbe, rangierung]

Recurring settings are among others rand (margin), spalten (columns), schriftfeld (title block), schriftfeld_art, schriftfeld_anteile, kabel_gedreht, da_nummern and buchten_je_blatt.

8   What applies on the sheets

  • No heading above the table — which strip a sheet shows is said by the title block; the table starts at the margin and has the room.
  • Pin stands above the number and above a and b: a column without a heading of its own belongs to the previous one.
  • No text runs beyond its field. If a designation, a remark or a cable name does not fit, the type is made smaller for that field only — down to 5 pt; below that it is shortened and an „…" shows that something follows.
  • The frame layout fills the sheet: the boxes grow as far as the page allows, and what is left over is distributed as air between the bays and the strips — no empty strip at the margin. The labels of the strips stand at the left edge of the sheet, in line with the heading and the title block below it.
  • In the frame layout there is no grid: only the cable is drawn, free areas stay unbroken. No supplied template carries pair numbers; whoever wants them sets da_nummern: true. In the editor every strip stays divided — that is where you click.
  • On the strip sheet the same holds for the cable column: the row lines end before it, the cable stands as a block across its rows.

9   Output

WayWhat comes out
File ▸ As PDF… (Ctrl+E)Cover sheet, frame layout and one sheet per strip — the required format.
File ▸ As Excel workbook…At the front the same sheets in the sheet layout, behind them the data as a table: data per wire, cables per strip, project data — filterable and sortable.
File ▸ As CSV…Plain data, one row per wire.

The Excel workbook takes over the order and width of the columns, the font sizes, the row heights, the merged cable block including its rotation and the setup for A4. The title block looks like the one on the sheet as well: the same framed block in the arrangement of the sheet template — with Mit Anschriften the matrix of date and name at the top left, frame, number and strip at the bottom left, the two addresses in boxes of their own on the right. The frame layout carries it too, and the cover sheet lists the same rows as the printed one.

The pages are filled just as in the PDF: row heights, cell sizes and the air between them come from the sheet model, the bays of the frame layout stand side by side, and from three bays on each one gets a sheet of its own — exactly as when printing. Printing puts each sheet on one page in width and height.

The title block stands at the foot of the sheet as it does on the printed one: the free area lies above it, not below.

All the same, the workbook cannot imitate a PDF: Excel is a grid, the sheet a drawing — the cable block is merged across its rows instead of drawn freely.

10   Files, folders and backup

WhatWhere
Project filewherever you save it, .vtly.json
Working folderWindows: daten\ next to the program. Linux: ~/.config/Verteilerly
SettingsVerteilerly.conf — one file, never the registry

In the working folder lie vorlagen/ (templates), blattvorlagen/ (sheet templates) and kabeltypen/ (cable types) as YAML. What is missing the program puts there at startup. A supplied file is only refreshed if it still lies exactly as it was put there — your own changes stay untouched.

Managing templates — Settings ▸ Frame templates… (Ctrl+Shift+V) renames a template or deletes it, a supplied one as well: whoever never needs one should not have it in the menu with every new frame. What is renamed is the name, not the identifier — that is the file name. Deleted supplied templates stay deleted, even after a restart; the button Restore supplied templates brings them back exactly as they were delivered — changed ones as well. Your own templates stay untouched by it.

A frame template is a file in vorlagen/. The even frame needs three numbers:

id: 40da-4x10
name: "40 DA - 4 Leisten zu 10 DA"
beschreibung: "Vier Leisten in einer Bucht, je 10 Doppeladern."
buchten: 1
leisten_je_bucht: 4
da_je_leiste: 10

An unevenly equipped one carries a list under buchten — one row per bay — instead of the number:

id: bunter-keller
name: "Bunter Keller"
buchten:
  - {leisten: 4, da: 10}
  - {leisten: 2, da: 20}
  - {leisten: 6, da: 8}

The program writes both itself when you choose Save as template in the dialog; created by hand it is read just the same. A new file in the folder is offered at the next start without anything having to be changed in the program.

Language — Settings ▸ Language switches the interface to Deutsch or English: menus, dialogs, buttons, hints and messages. The choice applies after a restart — the menus are labeled once when the window is built. It belongs to the workplace and is kept in the Verteilerly.conf.

The sheets are not switched over with it: what is on them is your document and not a program interface — the words of the title block can be changed per project anyway (Advanced: change the wording on the sheet). The names of the supplied templates stay German as well: they are data in the working folder, and you may rename them.

In the Verteilerly.conf are the sheet template, the language, the notation of the jumpers, the free-text switch, the appearance and the remembered project data. What concerns the single frame is in the project file instead.

Backup and restore — Settings ▸ Back up templates and settings… packs frame templates, sheet templates, cable types and the settings into a ZIP file; … restore… brings them back. In both directions check marks choose what comes along, and the dialog shows beforehand what is in the package. On restoring, only the known subfolders and only YAML are taken over — a package from someone else cannot create anything outside the working folder.

12   Information about the program

Help ▸ Documentation (F1) opens this page: on the left the table of contents, on the right the text.

Searching. Above the text is a search field (Ctrl+F). The search runs as you type, from the second character on; upper and lower case make no difference. Every match is highlighted, the one currently aimed at strongly, the others faintly, and on the right stands which of how many it is. Enter, F3 or the arrow › go to the next one, Shift+F3 and ‹ to the previous one — at the end it starts over. It begins at the place that is currently visible: whoever is reading the section about cables means the next match from there. Esc clears the search away; pressed again, it closes the window.

Help ▸ About Verteilerly lists every component with version, license and task — Python, PySide6, Qt, ReportLab, openpyxl, PyYAML —, together with system, working folder, settings file and the folder with the licenses. The versions come from the running program, not from a maintained list.

License. Verteilerly is free software under the GNU GPL, version 3, and comes without any warranty. You may pass it on and change it, commercially as well; whoever passes it on passes on the source code or offers it. The components are under LGPL, BSD, MIT or PSF — Qt is linked dynamically and exchangeable in the image, as the LGPL requires.

The complete license texts stand in the about window as links — GNU GPL, GNU LGPL and the Qt source code. Besides that they are put into the working folder at the first start (lizenzen/, with QUELLEN.txt, which says for every component where its source code comes from): that way they can be read without a network as well and stay there when the program has ended. They are in the AppImage itself too, but there in the mount point, which the operating system clears away when the program ends.

On the command line --selbsttest answers the same question briefly and without a window; --python script.py runs a script of your own against the packed program.
